00 / QUICK START

한 번에 실행하고, 단계별로 되짚기

Docker와 Docker Compose만 설치되어 있으면 됩니다. Python과 학습 패키지는 trainer 이미지 안에 들어갑니다. 처음 실행할 때는 이미지·데이터 다운로드를 위해 인터넷이 필요합니다.

노드당 최대 512 MiB의 RAM 저장소를 사용합니다. 컨테이너가 종료·재생성되면 인덱스와 업로드 모델이 사라집니다. 아래 시작·종료 명령은 이 선택에 맞춰 바뀝니다.

이 가이드를 검증한 Docker VM은 디스크 사용률이 높아 기본 디스크 보호 기준에 걸렸습니다. 보호 설정을 끄지 않고 RAM 구성으로 검증했습니다. 여유 디스크가 충분하고 결과를 유지하고 싶다면 ‘Docker 볼륨’을 선택하세요. RAM 구성은 Compose 2.24.4 이상이 필요합니다. Docker의 !override 설명 ↗

학습에 필요한 id/title/overview/release_year만 선택했습니다. 개봉일이 없는 영화 471건의 연도는 0으로 표시합니다. 판정에 포함된 영화 중에는 이런 경우가 13건 있습니다. 0은 실제 개봉 연도가 아니라 결측 표시이므로 연도 통계·계수에 영향을 줍니다. 실서비스에서는 결측 여부 특징이나 별도 대체값을 검토할 수 있습니다.

동일한 qid·문서·grade가 반복된 5행만 하나씩 제거했습니다. 판정이 서로 충돌하면 자동으로 선택하지 않고 실행을 중단합니다. 변경 내역과 다운로드 SHA-256은 data/provenance.json에 기록합니다. 원문 로더는 다른 메타데이터가 빠진 영화도 제외하지만, 이 실습은 필요한 세 특징만 골라 전체 영화를 유지합니다.

데이터는 저자의 고정 데이터 커밋 ↗에서 내려받습니다. 압축 파일은 약 69 MB, 원본 JSON은 약 260 MB입니다. 준비 후에는 필요한 필드만 담은 약 26 MB JSONL을 사용합니다. 데이터 출처는 TMDB이며, 이 가이드는 책의 학습용 배포 데이터를 사용합니다.

쌍의 차이에서는 같은 평균이 상쇄되므로 실제 코드의 (xA − xB) / std는 zA − zB와 같습니다. 평가와 검색 점수에서는 평균을 생략하지 않습니다. fit_intercept=False로 이번 선형 모델은 가중합만 사용합니다.

평가는 판정된 문서들 안에서 합니다

P@5(q) = 상위 5개 중 grade=1인 문서 수 ÷ 5
평균 P@5 = 평가 검색어별 P@5의 평균

기준선은 title_bm25 + overview_bm25, LTR은 w · z로 판정 문서들을 정렬합니다. 이는 평가용 검색어의 판정 문서 안에서 순서를 비교하는 오프라인 평가입니다. 전체 검색 후보를 얼마나 잘 찾는지, 실제 사용자의 만족도가 좋아졌는지까지 검증한 값은 아닙니다.

Linux는 호스트, WSL은 Docker의 Linux 환경, macOS는 Docker Desktop/Colima의 Linux VM 설정입니다. 이미 262144 이상이면 변경할 필요가 없습니다. 아래는 해당 오류가 있을 때 확인하는 명령입니다.

Linux 호스트 · 오류가 있을 때만
그대로 복사할 수 있습니다
sysctl vm.max_map_count
sudo sysctl -w vm.max_map_count=262144
Windows + Docker Desktop WSL 환경
그대로 복사할 수 있습니다
wsl -d docker-desktop -u root sysctl -w vm.max_map_count=262144
macOS + Colima 환경
그대로 복사할 수 있습니다
colima ssh -- sudo sysctl -w vm.max_map_count=262144

재부팅 후 유지하려면 사용하는 Linux VM의 설정 방식에 맞게 저장해야 합니다. Docker Desktop 버전에 따라 VM 접근 방식이 다를 수 있으므로 공식 설치 문서를 함께 확인하세요. OpenSearch 호스트 설정 ↗

19200 포트를 이미 사용 중이라면?

LTR_HTTP_PORT=19201을 지정해 시작하면 됩니다. 호스트의 curl 주소도 19201로 바꾸세요. trainer는 내부 주소 http://opensearch-node1:9200를 쓰므로 그대로 동작합니다.

시작 포트 변경 예시
그대로 복사할 수 있습니다
LTR_HTTP_PORT=19201 docker compose -f compose.yaml -f compose.ram.yaml up -d --wait opensearch-node1 opensearch-node2
