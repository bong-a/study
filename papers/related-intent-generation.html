01문제와 핵심 아이디어

검색어는 짧고,

“우유”를 검색한 사람은 우유만 필요할까? 대체 음료를 찾을 수도, 아침 식사를 준비할 수도, 스무디를 만들 수도 있다. 이 논문은 이런 검색어 뒤의 가능한 목적을 여러 갈래로 펼쳐 상품을 더 발견하게 한다.

02생성과 검색의 역할 분담

생성할 것은 ‘의도’,
찾아올 것은 ‘실제 상품’.

모델의 출력은 상품 ID가 아니라 묶음 제목과 의도 검색어 목록이다. 각 검색어를 기존 검색 엔진에 넣어 카탈로그의 상품을 채운다. 정확히 일치하는 상품은 기존 검색 경로가 계속 담당한다. §3.1–3.2 ↗

많이 찾는 검색어와 드문 검색어를 다르게 처리한다.

Head는 자주 들어오는 검색어, Tail은 상대적으로 드문 검색어다. 자주 쓰이는 결과는 미리 만들어 재사용하고, 확장 가능한 tail 일부에 학생 모델을 투입한다.

80%는 “80%의 검색에 발견 기능을 제공한다”는 뜻.
검색 정확도 80%, 상품의 80% 발견, 또는 쿼리 종류의 80%를 뜻하지 않는다.

03교사의 출력을 학생에게 학습시키기

큰 모델의 판단을,
더 저렴한 모델로 옮긴다.

증류(distillation)는 강한 모델이 만든 답을 학습 자료로 써서 다른 모델이 비슷한 작업을 수행하도록 가르치는 방법이다. 여기서 기존 운영 모델과 교사 모델을 혼동하지 않는 것이 중요하다.

1. 쿼리 20,000개 준비

Head와 tail을 50:50으로 샘플링한다.

2. GPT-5.1이 학습 정답 생성

브랜드·상품 속성·개념 태그·최근 구매 이력을 문맥에 넣고, 예시를 보여 주는 few-shot 방식으로 제목·의도 JSON을 생성한다.

3. Qwen3-30B-Instruct를 LoRA로 학습

학습 70%, 검증 30%로 나누고 교사 JSON의 다음 토큰을 맞히도록 학습한다. LoRA는 작은 추가 가중치를 학습하는 방식이다.

4. Tail 일부를 실시간 처리

운영 시 문맥이 부족한 상황에 대비해, 메타데이터를 제거한 학습 예제도 일부 섞는다.

Qwen3의 강점은 새로움, 약점은 다양성과 일관성이다. Head에서 새로움은 0.853 → 0.911로 높아지지만, 다양성은 0.917 → 0.894, 제목 일관성은 0.964 → 0.918로 낮아진다. “모든 생성 품질이 개선됐다”는 요약은 맞지 않는다.

심사자는 사람과 얼마나 일치했을까?

전문가 3명이 50개 (쿼리, 제목, 의도 검색어) 튜플을 평가하고, 다수결을 기준으로 GPT-5의 판단을 비교했다. 사람 검증은 7개 전체가 아니라 아래 3개 지표에 대해 수행했다.

08운영 경험과 해석의 경계

성과와 함께 읽어야 할
여섯 가지 빈칸.

01

오프라인 결과가 매출 증가는 아니다.

온라인 A/B 테스트와 장바구니 크기·세션 매출·롱테일 노출 효과는 향후 과제다. 공급자 노출의 균형 개선도 아직 정량 검증 결과가 없다.

02

로그에는 기존 검색의 노출 편향이 남는다.

과거에 보인 상품이 구매되기 쉽다. 카테고리 기반 평가와 필터링만으로 새 시스템의 인과적 효과를 분리할 수 없다. top-10 필터 설명 자체도 일치하지 않는다.

03

30% 비용의 재현 조건이 없다.

초록 기준으로 학생 추론 비용이 교사의 약 30%다. 전체 서비스 비용이나 GPT-3.5 캐시 대비 비용이 아니다. 하드웨어·토큰량·단가·실제 지연시간은 제시되지 않는다.

04

학습 때의 풍부한 문맥이 운영에는 없을 수 있다.

메타데이터 없는 요청에서 학생 품질이 낮아지는 문제가 있었다. 문맥을 제거한 학습 예제를 섞어 완화했지만, 비율과 개선 폭은 공개되지 않았다.

05

그럴듯하지만 없는 브랜드를 만들 수 있다.

없는 브랜드명은 검색 결과가 비거나 적어 캐러셀이 표시되지 않는 경우가 있다. 사전 브랜드 어휘 검증은 적용하지 않으며, 극단적 tail은 기존 검색으로 돌린다.

06

비교 대상과 유지보수도 더 필요하다.

공동구매 그래프·전통적 쿼리 재작성과의 직접 비교는 미래 과제다. 쿼리·카탈로그 변화에 따른 결과 갱신, 교사 변경 시 재증류가 필요하다.

§5–6의 한계와 보고 범위를 정리했다. 온도를 높이면 다양성이 늘어도 캐러셀 제목이 주제에서 벗어날 수 있어, 저자들은 일관성을 기준으로 T=1.0을 선택했다. §5 · §6

09다시 핵심으로

검색어를 이해하는 다음 단계는,
가능한 목적을 구조화하는 일.

짧은 검색어에서 여러 의도를 만들고,
그 의도를 기존 카탈로그 검색에 연결한다.
잘 찾았는지는 의미 품질과 구매 신호로 따로 확인한다.

실무에 적용한다면, 생성 모델 선택만큼 의도와 실제 상품의 연결, 빈 결과의 처리, 기존 검색으로 돌아갈 조건, 평가 데이터의 정의가 중요하다. 이는 논문의 구조와 한계에서 도출한 해설자의 정리다.

용어를 한 번 더 확인하기
Recall set
랭킹·표시 단계에 앞서 검색으로 확보한 상품 후보 집합.

검색어에 직접 쓰이지 않았지만 함께 고려할 수 있는 목적.

학습 답을 만드는 모델 / 그 답을 학습하는 모델.
LoRA
모델 전체를 모두 조정하는 대신 작은 추가 행렬을 학습하는 미세조정 방법.
